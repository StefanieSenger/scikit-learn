- |Feature| scikit-learn estimators consuming `sample_weight` now auto-request it on
  the methods that accept it when metadata routing and auto-requests are enabled via
  :func:`~sklearn.set_config`. They opt in by inheriting from
  :class:`~sklearn.utils.metadata_routing.AutoRequestSampleWeightMixin`, which
  third-party estimators can use as well;
  :func:`~sklearn.utils.metadata_routing.AutoRequestMixin` does the same for any
  metadata. By :user:`Stefanie Senger <StefanieSenger>`.
